# 稿间 · 征稿写作工作台

适配手机和电脑的单人网页原型。导入征稿后，自动提取要求、生成初稿、进行两路独立评审及有限轮修改，最后由作者审阅和导出。原有 Scrapy 汽车爬虫保持不变，本项目位于独立目录。

## 启动

需要 Python 3.12 或更新版本。通过 GitHub 下载 ZIP 后先解压，在解压后的仓库目录进入 `writing-studio` 文件夹。

macOS / Linux 首次安装：

```bash
cd writing-studio
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
bash run.sh
```

Windows 在仓库目录打开 PowerShell，执行：

```powershell
cd writing-studio
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.lock
.venv\Scripts\python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

服务默认监听本机 8000 端口。浏览器访问该端口即可使用。若需要从同一可信局域网的手机访问，可设置 `WRITING_STUDIO_HOST=0.0.0.0` 后启动，用电脑的局域网 IP 和 8000 端口访问。尚未包含多用户登录，请在本机或可信网络运行。

Windows 手机访问时，把启动命令中的 `--host 127.0.0.1` 改成 `--host 0.0.0.0`。手机和电脑须在同一网络，电脑防火墙也需要允许该端口的局域网访问。

可用 `WRITING_STUDIO_PORT` 更改端口，用 `WRITING_STUDIO_DATA` 指定数据目录。默认保存在本目录下被 Git 忽略的 `data/`，包含数据库、稿件、设置与截图。备份时停止服务后复制该目录。密钥保存在仅当前用户可读写的本地数据库，不返回给网页；数据库未进行额外的磁盘加密。

## 体验流程

1. 打开工作台，自带一条明确标记为虚构的示例征稿，后台会完成演示任务。
2. 新建任务，可以粘贴征稿正文、输入文章链接，或上传最多 8 张 JPG/PNG/WebP 截图（每张最多 5 MB）。
3. 先选择“演示模式”，不需要 API 密钥。演示生成和点评使用本地规则与模板，界面、导出稿件均有演示标记，不能作为真实模型效果或投稿作品。
4. 查看任务的要求、稿件版本、两路评审、硬性检查和待处理事项。手动编辑后，旧评审会失效；可以提交定点修改意见进行重写和重新评审。
5. 完成最后确认后标记已审阅，可导出 Word、纯文本或邮件草稿。应用没有发送邮件、投稿或发布功能。

## 真实模型

### 免费额度快速接入：魔搭 ModelScope

应用已内置魔搭预设。“免费”指账号的每日免费 API 调用额度，具体额度、认证要求和可用模型以官方账号控制台为准，不承诺无限或永久免费。官方额度说明：[ModelScope 官方项目文档](https://github.com/modelscope/ms-agent/blob/fd6ea88422a399db8b303848dc6c6ec4e17daf6e/docs/zh/Projects/deep-research.md#L151)。

1. 到[魔搭官方 Token 页面](https://modelscope.cn/my/myaccesstoken)注册或登录，领取自己的 Token。不要把 Token 发到聊天、提交到 GitHub，或填进源码。
2. 在应用“模型设置”选择“魔搭 ModelScope · 每日免费额度”，点击“填入表单”。预设不会自动保存，也不会发起模型调用。
3. 将 Token 粘贴到“API Key / Token”，点击“保存模型设置”。初次使用时，独立评审 API 地址和密钥可以留空，沿用写作服务。
4. 点击“测试写作”和“测试评审”。需要截图识别时，再点击“测试截图模型”。这些按钮会发起简短的真实请求，可能消耗少量免费调用额度；只有收到有效响应才会显示成功。
5. 如果提示模型不可用，点击“读取可用模型”，或在官方控制台复制有权限的模型 ID，填入相应模型字段并重新保存、测试。模型列表本身不代表免费或支持图像，仍以官方说明为准。
6. 新建任务时选择“真实模型”，即可执行实际写作与评审。初次建议最多自动修改 1 轮，并先用不涉及个人隐私的样例正文验证。

[查看手机端配置界面示意](docs/modelscope-setup.png)（图中 Token 留空，尚未保存或连接）。

预设使用官方仓库中的候选配置，账号当前是否可用需要测试：

| 项目 | 配置 |
| --- | --- |
| API 地址 | `https://api-inference.modelscope.cn/v1` |
| 写作模型 | `Qwen/Qwen3-235B-A22B-Instruct-2507` |
| 评审模型 | `Qwen/Qwen3-235B-A22B-Instruct-2507` |
| 视觉模型 | `Qwen/Qwen3-VL-8B-Instruct` |

默认写作与评审使用同一模型的独立上下文。希望不同模型交叉点评时，可从账号可用列表中另选评审模型。每轮两路点评会分别消耗一次调用；额度用尽或限流时会显示失败原因，不会改成演示内容冒充真实结果。

已针对魔搭 Qwen3 文本请求关闭思考模式，避免结构化结果被思考内容占满。魔搭图片请求的长边超过 2048 像素时等比缩小；特别长的截图建议分成几张，以保留小字清晰度。连接测试成功只代表接口接受请求，不能证明整篇稿件质量或真实 OCR 准确率。

这里的接入适配、模拟协议和界面已测试；没有预置公共密钥，也没有用用户账号实际调用。真实连通最后需要你在本机应用填写 Token 并点击测试。

### 更新已有原型

先停止旧服务。ZIP 用户重新下载当前分支的 ZIP，解压后使用新的 `writing-studio` 文件夹；需要保留记录时，在服务停止期间将旧 `writing-studio/data/` 复制到新目录的同名位置。该目录含私人数据和本地密钥配置，不要上传 GitHub。使用 Git 的用户可在无本地冲突时拉取 `codex/gaojian-prototype` 分支。更新后重新启动服务并刷新网页；如果仍显示旧界面，在电脑上按 Ctrl+F5 强制刷新。

### 自定义兼容 API

硅基流动国内站的统一基础地址是 `https://api.siliconflow.cn/v1`，不需要单独申请地址。可以选择“硅基流动 · 已有 API Key”预设，或手动填入该地址。点击硅基流动密钥页面的复制按钮取得完整 Key，不能复制网页上带星号的遮罩文字。先保存地址和 Key，再“读取可用模型”；写作模型也可以从“模型广场”详情中的调用示例复制完整 ID。模型价格、免费额度和余额以账号控制台为准。

同一服务的评审模型留空时，会自动沿用写作模型。独立评审 API 地址有值时，需填写该服务自己的评审模型。设置不完整会列出缺少字段，尚未发起密钥认证；只有实际调用收到 401 才是服务商认证失败。遇到设置提示时，无需先认定 Key 已失效。

保存后，密钥输入框会清空，并显示“已保存（已隐藏）”；这是正常行为，测试会使用服务器保存的密钥，无需再次粘贴。留空再次保存、刷新网页和重启服务都会保留已有密钥。同一服务未单独设置评审密钥时，显示“沿用写作密钥”。“已保存”只表示配置已存储，连接是否可用需点击测试确认。

如果提示“请先填写并保存：写作模型、评审模型（独立评审服务）”，缺少的是模型 ID。可在密钥已保存的状态下先点击“读取可用模型”，选择完整 ID 并保存；无需先填写模型才能读取列表。只用硅基流动时，可以将“评审 API 地址”留空以复用写作服务及模型。使用另一家平台评审时，需为评审选择该平台自己的模型。每个测试按钮只检查对应角色的已保存配置。

视觉模型可以先留空，先确认文字写作和评审可用。百炼的 `qwen-plus` 与硅基流动模型 ID 属于不同服务，切换时请从对应平台重新选择。

在“模型设置”填写 OpenAI-compatible HTTPS API 地址、密钥、写作模型 ID 和评审模型 ID，然后在新建任务时选择真实模式。可为评审配置独立供应商的地址和密钥；留空地址时复用写作服务。两路评审使用独立上下文和不同检查重点，默认使用同一评审模型。

视觉模型为可选项，填写供应商支持图片输入的模型 ID 后可以识别截图。没有视觉模型时，截图任务会进入待补充状态，可粘贴正文继续；不会制造 OCR 结果。截图先按界面中排列的顺序发送，重叠内容的整理效果依赖真实模型，需要最后核对关键日期和投稿地址。

若运行环境限制外部网络，还需在环境设置中放行所选 API 服务的主机名，以及用于链接导入的 `mp.weixin.qq.com`。当前原型不自动修改网络规则；正文导入和本地演示无需这些外部连接。

也可通过 `WRITING_API_KEY` 注入写作服务密钥。客户端会员通常不提供 API 额度，需要自行开通供应商接口。

应用显示 token 用量及可配置的每日调用预算。模型不返回用量时采用保守估算，并标记估算状态。这不是人民币费用上限：不同模型的价格及 token 计算方式由供应商决定，建议同时在供应商侧设置费用限额。请求失败或响应丢失时，供应商实际计费也可能与本地记录存在差异。

## 自动流程与边界

- 自动修改上限为 1–3 轮。已完成的阶段、稿件版本与任务状态写入 SQLite；重启后从未完成步骤继续。中断瞬间正在执行的远程请求无法保证不被重复计费。
- 征稿原文明确禁止 AI 时停止生成；过期征稿停止生成；真实经历类征稿缺少素材时暂停。信息不完整的征稿会显示待确认项，作者最终核实。
- 字数统计采用中文汉字逐字、英文与数字连续串按词计数，忽略标点和空白，并在检查中说明口径。
- 链接导入限于 `mp.weixin.qq.com` 公众号文章的公共 HTTP/HTTPS 访问，禁止访问私有或回环地址，并检查重定向和响应大小。公众号可能拒绝服务端读取，此时可以在原任务补充正文。其他站点请粘贴正文。
- 一次任务处理一条征稿。合集文章应先截取目标征稿的完整段落；自动拆分多条征稿尚未实现，检测到多组明确的征稿方字段时会暂停并要求选择。
- 不包含微信公众号的每日自动订阅、登录微信、突破访问限制或自动操作第三方聊天客户端。
- 素材库是简单的作者素材文本，当前未实现逐条授权标签和向量检索。只应存放允许发送给所选模型的内容；设置真实模式后，这些素材和征稿正文会发给对应模型供应商。
- 任意模型之间意见一致不等于事实已核实；不保证录用、原创性认定或稿费。最终审阅由作者完成。

## 验证

```bash
python -m unittest -v test_app test_engine test_providers test_saved_credentials
```

测试使用独立临时数据库和本地演示引擎，不调用收费模型。机器可读接口定义路径为 `/openapi.json`，健康检查路径为 `/api/health`。真实供应商接入需要有效配置后另行验证，演示测试不能代表真实 API 已验证。

基础流程验证记录：25 项后端与模型协议测试通过；Chromium 桌面 1440px、手机 390px 浏览器流程通过，包括正文创建、未配置模型提示、两路评审、版本查看、编辑、定点修改、最终确认、Word 下载、截图排序及正文回补、素材保存和页面刷新。没有执行真实供应商 API 或实际 OCR 请求，也没有发送投稿。

免费 API 接入和配置回归另有 27 项测试，当前合计 52 项通过，覆盖保存后连接测试、账号模型列表、魔搭请求格式与图片尺寸、错误保留、评审默认复用、缺少字段提示、遮罩密钥校验、重启保留密钥和跨服务密钥隔离。另通过手机 390px、电脑 1440px 浏览器验证保存后隐藏密钥、读取模型、缺少模型提示、独立评审测试、刷新和留空重存后的连接调用；连接成功/失败和模型列表使用本地模拟供应商响应验证，不能当作真实账号连接成功。

## 文件

- `app.py`：HTTP 接口、后台任务调度、审阅门禁和文档导出。
- `engine.py`：规则提取、演示流程、真实模型调用、截图识别和链接读取。
- `providers.py`：官方平台预设、账号模型列表和真实连接测试。
- `store.py`：SQLite 存储。
- `static/`：无需构建步骤的响应式前端。
- `test_app.py`：隔离的功能集成测试。
- `test_engine.py`：通过本地模拟响应验证模型协议、预算和来源边界。
- `test_providers.py`：平台接入与凭据隔离测试。
- `test_saved_credentials.py`：密钥保存、隐藏显示后的连接调用、重启恢复及各角色配置状态回归。
- `requirements.lock`：此次验证使用的完整依赖版本；`requirements.txt` 记录直接依赖。

这是可运行的单人原型。公网部署前需要增加身份认证、HTTPS 入口及相应的访问与资源管理。
